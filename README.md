Iris Flower Classification Using Decision Tree

About the Project

My first Machine Learning project using the Decision Tree algorithm to classify Iris flowers into three species.

Dataset

The Iris dataset contains four measurements:

- Sepal length
- Sepal width
- Petal length
- Petal width

The model predicts one of three species: Setosa, Versicolor, or Virginica.

Technologies Used

- Python
- Scikit-learn
- Google Colab
- GitHub

How It Works

1. Load the Iris dataset.
2. Split data into training and testing sets.
3. Train a Decision Tree model.
4. Evaluate model accuracy.
5. Predict the species of a flower.

Example Prediction

Input: "[5.1, 3.5, 1.4, 0.2]"

Prediction: "setosa"

How to Run

Open "iris_decision_tree.ipynb" in Google Colab and run the code cells.
